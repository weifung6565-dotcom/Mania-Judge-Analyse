# tosu Mania Ratio Plugin

A tosu plugin for osu mania.
*AI-assisted code creation*
## Features

- Mania only
- MAX / Yellow 300 ratio
- MAX / Other judgments converted ratio
- Live display during gameplay
- Show final result on the result screen
- able to use in other's result/replay
- not support multiplayer now
- judge color and glow enable
- balance value enable

## Installation

Put this folder into:

tosu/static

## Requirements

- osu!lazer/osu!stable
- tosu

## Recommended
- checkout settings page in tosu website for better experience
